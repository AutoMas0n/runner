# Proposal

## Why

The termux widget currently has a single "▶ Run" button that opens the script-runner app. Adding an "aidhd" button provides a direct homescreen entry point to the aidhd task management system — add tasks, capture by voice, run the secretary, and open the web dashboard — without needing to open a terminal or web browser first. This turns the widget from a single-purpose script launcher into a compact task input hub.

## What Changes

- **Widget layout**: Replace the single TextView with a horizontal layout containing two side-by-side buttons: "▶ Run" (left, existing behavior) and "aidhd" (right, new, green color)
- **TaskWidget provider**: Add a second PendingIntent for the aidhd button, passing a `command=aidhd` extra to `MainActivity`
- **MainActivity**: When opened with `command=aidhd`, show a dedicated aidhd dialogue instead of the script list. The dialogue includes:
  - An `EditText` field for typing a new task title
  - A "Submit" button that sends the text to `octx x aidhd add` via RUN_COMMAND
  - A "Voice" button that runs `octx x aidhd voice`
  - A "Secretary" button that runs `octx x aidhd secretary`
  - A "Serve" button that starts `octx x aidhd serve --port 7317` in the background and opens `http://127.0.0.1:7317`
  - A back button to return to the script list
- **Wrapper scripts**: Create `~/.shortcuts/widget-aidhd-add`, `widget-aidhd-voice`, `widget-aidhd-secretary`, `widget-aidhd-serve` as thin wrappers calling the aidhd CLI
- **New IDs in R.java** (auto-generated via aapt): IDs for the new UI elements

## Capabilities

### New Capabilities
- `aidhd-widget`: The aidhd dialogue embedded in the widget app — text input for adding tasks, voice capture trigger, secretary invocation, and one-tap serve launch. This capability owns the UI layer that bridges the widget's visual frontend to the aidhd CLI commands.

### Modified Capabilities
- *(none — this is a new capability, no existing specs change)*

## Impact

- **Source files modified**:
  - `res/layout/widget_layout.xml` — 1 TextView → 2-button horizontal layout
  - `res/layout/aidhd_dialog.xml` — new layout for the aidhd dialogue view
  - `src/com/runner/TaskWidget.java` — second PendingIntent
  - `src/com/runner/MainActivity.java` — aidhd dialogue mode
  - `src/com/runner/R.java` — auto-regenerated by aapt
- **New files**:
  - `~/.shortcuts/widget-aidhd-add`
  - `~/.shortcuts/widget-aidhd-voice`
  - `~/.shortcuts/widget-aidhd-secretary`
  - `~/.shortcuts/widget-aidhd-serve`
- **Dependencies**: Assumes `octx` CLI is installed on the device with the `aidhd` arm on PATH. The wrapper scripts should detect missing `octx` and show a toast notification instead of silently failing.
- **Android compatibility**: No change to Android version requirements (currently minSdkVersion=24). The new views (`EditText`, `Button`) are already present in the android.jar framework on this device.
